📚 Quick Review — Revisão rápida antes do desafio

Leia rapidinho para lembrar o vocabulário antes de jogar.

Linking Words / Conectivos because = porque / pois although = embora / apesar de but = mas so = então / por isso and = e however = entretanto
Feelings / Emoções worried = preocupado(a) nervous = nervoso(a) excited = animado(a) afraid = com medo proud = orgulhoso(a) confused = confuso(a)
Prefixes / Prefixos un- pode indicar negação: unhappy im- pode indicar negação: impossible in- pode indicar negação: incorrect dis- pode indicar oposição: disagree re- indica repetição: rewrite pre- indica antes: preview
Suffixes / Sufixos -ful = cheio de: careful -less = sem: careless -ness = estado/qualidade: sadness -ly = modo: quickly -er = pessoa que faz: teacher -ment = ação/resultado: movement
Word Formation / Formação de palavras help + ful = helpful care + less = careless happy + ness = happiness friend + ly = friendly use + less = useless read + er = reader
Past and Memories / Revisão played = jogou / brincou visited = visitou watched = assistiu went = foi childhood = infância used to = costumava
